# Генераторы задач-близнецов

Близнец — задача того же приёма, что и настоящая задача ЕГЭ, с теми же объектами
и вопросом, но с другими числами и другим графиком. Марк сначала читает разбор
настоящей задачи, потом решает близнеца без подсказки.

## Файлы

- `gen/rnd.js` — детерминированный генератор случайных чисел (`RND.make(seed)`) и форматирование чисел.
- `gen/graph.js` — рисовалка графиков и таблиц (`GRAPH.plot(spec)`, `GRAPH.table(head, rows)`).
- `gen/kin-<key>.js` — по одному модулю на приём кинематики. `<key>` — ключ приёма из `lessons/plan-fiz.json`
  (`read_xs`, `slope_v`, `slope_a`, `rel`, `area_s`, `area_d`, `avg`, `pif`, `from_a`, `parab`, `eq`, `form`).
- `tools/gencheck.js` — проверка модуля: `node tools/gencheck.js gen/kin-<key>.js --seeds 40 --out /tmp/x`.

## Контракт модуля

```js
/* global RND, GRAPH */
const GEN = {
  key: "slope_v",                       // ключ приёма
  title: "Скорость по наклону графика", // название приёма, как в plan-fiz.json
  kinds: [                              // виды задач внутри приёма — по одному на подвид из плана
    {
      id: "one_part",                   // латиница, без пробелов
      title: "Скорость на одном участке",
      like: ["sd970326", "sd947520"],   // id настоящих задач банка, которые этот вид повторяет
      make(rnd) { … return task; }
    },
  ],
};
if (typeof module !== "undefined" && module.exports) module.exports = GEN;
if (typeof window !== "undefined") (window.GEN = window.GEN || {})["fiz:" + GEN.key] = GEN;
```

`make(rnd)` получает `rnd` из `RND.make(seed)` и возвращает объект:

| поле | тип | что это |
|---|---|---|
| `plain` | string | Полный текст задачи в формулировке ЕГЭ. Такой же стиль, как у настоящих задач банка: «На рисунке представлен график зависимости координаты x тела от времени t. Определите… Ответ запишите в метрах.» Все числа, нужные для решения, либо в тексте, либо на графике. |
| `svg` | string \| null | График от `GRAPH.plot(...)`, если задача с графиком. |
| `table` | string \| null | Таблица от `GRAPH.table(...)`, если задача с таблицей. |
| `answer` | string | Ответ как в ЕГЭ: `"5"`, `"−10"`, `"2,5"`. Делай через `RND.fmtAns(x)`. Никаких единиц. |
| `unit` | string | Единица ответа: `"м"`, `"м/с"`, `"м/с²"`, `"с"`, `"км/ч"`. |
| `simple` | string | Одна фраза «о чём задача», человеческим языком, как поле `simple` в `lessons/q-fiz.json`. |
| `raz` | object | Разбор: `{ dano: [..], plan: [..], steps: [{ t, p: [..] }], ans, err }` — ровно тот же формат и тот же простой язык, что в `lessons/razbor-fiz-1.json`. |
| `dbg` | object | `{ graph: <spec, переданный в GRAPH.plot>, vars: { … все числа задачи и промежуточные результаты … } }`. Нужен проверке: по `vars` проверяющий пересчитывает ответ сам. |

## Правила для чисел

- Всё должно решаться в уме или столбиком: ответы — целые или с одним знаком после запятой
  (`2,5`, `7,5`, `0,5`, `1,5`). Никаких `3,333`.
- Точки графика — только на узлах сетки. Шаг сетки выбирай «красивым» (1, 2, 5, 10, 0,5) и
  такой, чтобы клеток было 6–14 по каждой оси.
- Подписи осей кратны `tick`. Ось времени начинается с 0.
- Числа в тексте — через `RND.fmtNum` (запятая, а не точка). Отрицательные — с типографским минусом `−`.
- Варьируй не только числа, но и «декорации»: тело / автомобиль / велосипедист / электрокар /
  материальная точка; секунды / минуты там, где это уместно и не ломает решение.
- Не делай близнеца легче настоящей задачи: если в настоящей были отрицательные координаты — пусть
  будут и в близнеце (хотя бы в части зёрен, `rnd.chance(0.5)`).

## Правила для разбора (`raz`)

Смотри `lessons/razbor-fiz-1.json` — это образец языка и структуры, повторяй его:

- `dano`: 3–5 коротких строк. Что на картинке (какие оси, в каких единицах). Какие числа снять
  и как («находишь на нижней оси секунду, ведёшь вверх до линии, потом влево — читаешь число»).
  Что найти.
- `plan`: 3–4 строки, каждая начинается с глагола: «Берём…», «Считаем…», «Делим…».
- `steps`: 3–6 шагов, у каждого заголовок `t` и строки `p`. Формулы — отдельной строкой с префиксом
  `"f: "` в записи приложения: дробь `(a)/(b)`, индекс `v_1`, `x_0`, степень `t^2`, умножение `·`,
  минус `−`, корень `√(…)`. После формулы — строка «Читается так: …» словами. При подстановке —
  строка, откуда взялось каждое число («60 — где тело на 12-й секунде, 40 — на 4-й»). Каждое
  арифметическое действие показано отдельно (минус на минус, деление на 0,5 = умножение на 2).
  Последний шаг — «что получилось» и проверка на здравый смысл.
- `ans`: `"2,5 (метра в секунду, со знаком плюс)"` — число + единица словами в скобках.
- `err`: одна типичная ошибка с конкретным неверным числом и что запомнить.
- Короткие фразы. Одна мысль на предложение. Обращение на «ты». Термин объясняется бытовым словом
  в той же фразе, где встретился, и дальше используется бытовое слово.
- Все числа в разборе — из этой задачи. Подставляй через шаблонные строки, не оставляй чисел
  «из примера».

## Как проверять

```bash
node tools/gencheck.js gen/kin-<key>.js --seeds 40 --out /tmp/gen-<key>
```

Должно вывести `OK`. В `/tmp/gen-<key>/` — HTML-образцы по два на вид, открой и посмотри глазами:
график читается, числа на узлах, текст задачи и разбор сходятся, ответ верный.
