# Марк готовится — ЕГЭ 2027

Подготовка к ЕГЭ по физике: задание 1 (кинематика) разобрано целиком —
142 настоящие задачи, разложенные по формулам, с пошаговым разбором.

## Как устроено

Задачи сгруппированы не по темам, а **по формуле, которой решаются**, и
по тому, сколько формул нужно: одна, две или три. Внутри задачи разбор
идёт цепочкой:

1. вопрос с вариантами — что тут вообще надо сделать;
2. формула и почему именно она в этой задаче;
3. какие числа нужны и откуда их брать;
4. наводящие вопросы, чтобы достать каждое число;
5. подстановка с числами этой задачи — считаешь сам и проверяешь ответ.

Разборы написаны заранее и работают офлайн. Кнопка «Объяснить проще»
пересказывает условие обычными словами через нейросеть — для неё нужен
свой токен, он хранится только в браузере.

## Откуда задачи

Условия, картинки и официальные решения — с сайта «Решу ЕГЭ»
(sdamgia.ru). Структура заданий, баллы и уровни — по спецификации
и кодификатору ФИПИ 2027 года.

## Запуск

Статика, сборка не нужна: открыть `index.html` или отдать любым
статическим сервером.

## Инструменты

- `tools/bank2.py` — выкачивает банк задач
- `tools/kin1.py` — исходник разборов задания 1, собирает `lessons/*.json`
