# Эталон курса: как обернуть любое задание ЕГЭ в понятную теорию

Документ описывает, как устроен курс по одному номеру задания. Первое задание (кинематика)
собрано по этому образцу; каждое следующее собирается так же.

## Кому адресован текст

Ученику, который базовый курс физики не помнит. Не «повторяет перед экзаменом», а разбирается
впервые. Сухой математический язык ему не заходит.

Из этого следуют правила, которые важнее любых других:

1. **Сначала знакомая ситуация, потом термин.** Не «рассмотрим равномерное прямолинейное
   движение», а «ты едешь в поезде и пьёшь чай». Термин появляется после того, как мысль уже
   понятна, и объясняется в той же фразе, где встретился.
2. **Одна мысль — одно предложение.** Длинные периоды с причастными оборотами не читаются.
3. **Обращение на «ты».** Так же, как в разборах задач.
4. **Каждое число объяснено.** Откуда взялось, что означает. «60 — это где тело на 12-й секунде».
5. **Формула читается словами.** После каждой формулы строка «Читается так: …».
6. **Никаких «очевидно», «легко видеть», «как известно».** Если бы это было известно, курс был бы
   не нужен.
7. **Иллюстрация к каждой новой мысли.** Текст без картинки — только там, где рисовать нечего.

## Блок одного приёма

Приём — это группа задач с общим ходом решения (в первом задании их двенадцать). Каждый приём
оборачивается в один и тот же блок:

| Шаг | Тип | Что делает |
|---|---|---|
| 1 | `teach` × 2–4 | Готовит к формуле: откуда она берётся, что означает, как узнать приём в условии. С иллюстрацией. |
| 2 | `quiz` × 1 | Вопрос на понимание, без вычислений. Проверяет мысль, а не арифметику. |
| 3 | `warm` | Упрощённый пример: тот же ход, но числа крошечные и круглые. Решение целиком на виду. |
| 4 | `show` | Настоящая задача ЕГЭ вместе с готовым разбором. |
| 5 | `solve` | Близнец: те же объекты и вопрос, другие числа. Решает сам, разбора нет. |
| 6 | `real` × N | Остальные настоящие задачи этого подвида. Решает сам, разбор открывается после ответа. |
| 7 | `recap` | Итог приёма: что теперь умеешь, формулы, где тут ошибаются. |

Шаги 3–6 повторяются для каждого подвида внутри приёма.

Порядок нарушать нельзя: **упрощённое → настоящее с разбором → сам на близнеце → сам на
настоящем**. Это и есть постепенный подход к реальному заданию.

## Требование полноты

Курс считается собранным, только если:

- покрыты **все подвиды** приёма — у каждого есть свои `warm`, `show`, `solve`;
- **каждая задача ядра** встречается в курсе хотя бы раз — как `show` или как `real`;
- у каждого `show` и `real` есть написанный разбор в `lessons/razbor-<sid>-<n>.json`;
- у каждого `solve` есть рабочий вид в `gen/kin-<key>.js` с независимой проверкой ответа.

Проверяется скриптом `tools/coursecheck.js` — он не пропустит пропуск.

## Формат шагов

```json
{ "t": "teach", "part": "Часть 2. Как читать графики", "title": "…",
  "ill": "readPoint",                    // имя функции из gen/draw.js
  "p": ["абзац", "абзац"],
  "f": [["v_x = (x_2 − x_1)/(t_2 − t_1)", "что означает"]],
  "note": "что запомнить" }

{ "t": "quiz", "part": "…", "q": "вопрос", "opts": ["…","…","…"],
  "ok": "верный вариант дословно", "why": "почему", "ill": "…" }

{ "t": "warm", "part": "…", "title": "…", "lead": "подзаголовок стадии",
  "q": "условие с маленькими числами", "ill": "…",
  "steps": ["строка", "f: формула", "строка"],   // «f: » — формула в записи приложения
  "a": "ответ словами", "note": "правило, которое отсюда следует" }

{ "t": "show", "part": "…", "id": "sd969870" }
{ "t": "solve", "part": "…", "key": "read_xs", "kind": "signed" }
{ "t": "real",  "part": "…", "id": "sd930022" }

{ "t": "recap", "part": "…", "title": "…",
  "can": ["умеешь то", "умеешь это"],
  "f": [["формула","что означает"]], "trap": "где тут ошибаются" }
```

Запись формул — своя, не LaTeX: дробь `(a)/(b)`, индекс `v_1`, степень `t^2`, умножение `·`,
минус `−`, корень `√(…)`. Числа по-русски, через запятую: `2,5`.

## Иллюстрации

Рисунки живут в `gen/draw.js`, каждый — функция без аргументов, возвращающая строку `<svg>`.
Подписи длиннее нескольких слов выносятся под рисунок через `withCaption` — она переносит строки
по ширине, поэтому текст не обрезается на телефоне.

Рисунок должен показывать **механизм**, а не украшать страницу. Если картинку можно заменить
фразой без потери, она не нужна.

## Проверка перед сдачей

```bash
node tools/coursecheck.js lessons/course-fiz-1.json
```

Скрипт проверяет: все ссылки на задачи и виды существуют, у каждого `show`/`real` есть разбор,
покрыты все подвиды и все задачи ядра, у `quiz` верный ответ входит в варианты, формулы
записаны в нотации приложения и разбираются `math.js`, имена иллюстраций существуют.
